# North Star

The question this project keeps returning to, and the standard it holds itself to when
deciding whether it has made progress.

> **What can a local learning mechanism actually represent, carry and change — and where
> does that stop?**

Everything else in the repository is downstream of that sentence. The theory is about the
representational limits of an update rule; the experiments are about whether a stated
mechanism is present, whether it arrives, and whether it changes anything measurable; the
protocols exist because a claim about a limit is only worth making if it can be checked.

## What counts as progress

1. **A stated limit, checkable from source or from a measurement.** A bound that can be
   read off an implementation before running it is worth more than a result that requires
   trusting the run.
2. **A mechanism shown to be present, not merely configured.** Arrival is verified, not
   assumed.
3. **A negative result with a criterion.** It removes an explanation and it can be cited.
4. **A measurement that was shown to be able to fail.** An instrument that has never
   returned a negative has not been validated.

## What does not count as progress

- A larger run of the same experiment.
- A parameter that moved a number without a mechanism behind it.
- A roadmap advance with no decision record.
- A capability described in a vision document as though it had been demonstrated.

## The standing disclaimer

This project investigates whether particular mechanisms can carry particular information.
It does not claim general intelligence, human-like cognition, or open-ended autonomous
learning, and nothing here should be read as making that claim.
