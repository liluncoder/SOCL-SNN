# SOCL-SNN

**脉冲神经网络中的自组织持续学习**
（Self-Organizing Continual Learning in Spiking Neural Networks）

一个独立研究项目，研究脉冲神经网络中的局部学习、突触信用分配、时间信息处理与自适应机制。

本项目探索一个神经系统如何通过**局部**机制从经验中学习——这些机制只能看到单个突触或单个细胞所能看到的东西——以及这类机制能够承载什么、不能承载什么。

这是一个仍在进行中的实验项目。它不主张通用智能、类人认知或开放式自主学习，其范围被证据、实现成熟度与可用算力刻意限定。

---

## 愿景

长期目标是一个**持久自适应系统**：它持续运行、感知、维持内部状态、记忆经验、行动，并能够随时间修改自身的学习机制。这被称为 PAA（Persistent Adaptive Agent，持久自适应智能体），它是一项研究愿景，而不是这里已经存在的架构。

本项目自身的目标更窄，并且必须先达成：

> **一个局部学习机制究竟能够表征、承载和改变什么——以及它在何处止步？**

这个问题驱动下文的一切。它通过数学分析与受控计算实验来推进，顺序如下：

- 一个局部机制能够表征并传递什么信息？
- 信用分配是否改变了突触更新*以及*可观测行为——这是两个不同的问题，却常被混为一谈？
- 时间信息与空间信息能否被整合到足以被读出？
- 学习能否跨越连续的经验而存活？
- 在什么条件下，结构能够在不拆解已有有效部分的前提下适应？

SNN 是当前的基底，因为它让时间、局部性与代价变得显式。这并不是在假定脉冲计算已经足够。见
[`docs/VISION_PAA.md`](docs/VISION_PAA.md) 与 [`docs/NORTH_STAR.md`](docs/NORTH_STAR.md)。

## 已经确立的结论

七项结论，其成立与否与当前任务是否被解决无关。每一项都是关于这类机制能做与不能做什么的陈述，且每一项都可以从源码或从一次已记录的测量中得到核查。

1. **标量调制器无法寻址到突触。** 每个突触后细胞只有一个奖励值，翻转它的符号会精确地翻转整个更新——`dw(+1) = −dw(−1)` 在每个事件上逐位成立。一个细胞各入边上的相对模式没有改变，因此这次写入在它们之间不携带任何方向。

2. **可塑性按边的数量分配，而不是按相关性分配。** 一条占据 0.42% 突触的通路获得了总权重变化的 0.39%——按比例分配，对承载答案的那些边没有任何偏好。

3. **相反的奖励产生近乎平行的写入。** 奖励 +1 与 −1 对应更新之间的余弦相似度约为 **+0.42**，而不是 −1。

4. **单纯形权重预算禁止增长。** 当每个细胞的预算在单纯形上归一化时，`Σdw ≡ 0` 可由代数推出：权重只能被重新分配，永远不能被新增。

5. **在固定拓扑下，结构无法自我孕育。** 梯度流会在可表征的类别内部收敛，且没有任何局部判据能驱动拓扑的改变。此项被记录为一个开放问题，而不是一项能力。

6. **任务在学习效应还有余地之前就已饱和。** 在当时的实验场景中，2 倍不平衡下准确率已达 ≈0.94——答案是由连线承载的，因此学习已经没有可改进的空间。

7. **读出窗口可以使结果反转。** 对同一配置，在其响应已衰减之后再打分，会得到相反的答案：两个窗口下分别为 0.03 与 1.00。

结论 1、3、4 是**候选 1**（低维调制型信用分配的表征极限）的形式化内容；结论 2 是**候选 2**（符号反转与突触更新的边级分解）的测量侧。完整的登记册（含每条的状态与证据类型）见
[`research/FINDINGS.md`](research/FINDINGS.md)。

## 瓶颈

四项约束，按其实际产生束缚的先后排列。忽略前两项的结果无法解释，无论其效应有多大。

**1. 信用没有维度。** 更新是突触前迹的标量倍数，因此一个细胞上的每个突触都以相同比例移动——见结论 1–3。在这一项改变之前，任何行为差异都不能被归因于*学习*，而只能归因于本就存在的连线。解除方式：一个不单是活动函数的信用变量——带时序符号的资格迹、按分支的资格迹，或依赖状态的奖励。

**2. 任务被自身的连线解决。** 答案沿一条手工接好的通路传递，因此在某个机制来得及贡献任何东西之前，准确率就已经饱和——见结论 6。解除方式：一个线索到行动的映射并非预先内置的实验场景。

**3. 结构无法负担自身的代价。** 在单纯形预算下，连接可以被重新分配，但不能被创造，而且目前没有任何局部判据奖励保留某条连接——见结论 4–5。这就是关卡 4 与关卡 5 处于冻结状态而非排入计划的原因。

**4. 仪器可以使结果反转。** 在响应已经衰减之后读取的读出值，可能报告与事实相反的结果——见结论 7。没有一劳永逸的修复办法；这项检查必须每次运行，因此它是一条协议步骤，而不是一段文字说明。

前两项解释了为什么迄今没有任何东西被证明性地学会。第三项解释了为什么路线图不向前跳。第四项解释了为什么这里的任何数字都不会在没有检查的情况下被信任第二次。

## 遗留原型

早期开发产出了一个顺序式的五阶段原型：能量受限的脉冲网络、工作记忆、记忆驱动的行动、奖励调制学习，以及结构发育。它仅依赖 NumPy 运行；在 2500 个细胞规模下，每模拟一秒约需十秒实际时间。

它之所以被保留，是因为上述若干结论正是针对它测量的，而一个无法重跑的基线就不是基线。它不是当前的关卡结构。见
[`legacy/pipeline_v1/README.md`](legacy/pipeline_v1/README.md)。

## 方法论

实验遵循一个预注册的裁决流程。核心规则：

> **在运行之前定义裁决判据，先验证测量，再追加最终裁决，而不重写原始判据。**

具体而言：

1. 显式的假设与实验条件。
2. 预先定义的测量、阈值、样本量与最小可检测效应。
3. 仪器验证——在信任测量之前，先让它故意失败。
4. 确认干预已经到达系统，依据权重指纹而非假设。
5. 一次只改变一个实验变量。
6. 配对、种子级比较；效应须相对于种子噪声来报告。
7. 四种结果：有差异、等价、未决、作废。
8. 仅追加的记录，并显式注明适用条件。

仪器损坏或设置无效，被视为**既非**支持也非反对某一机制的证据。未决就报告为未决；“该设计无法检测到它”不等于“它不存在”。

底层原则：数学定义先于生物学类比；可证伪假设先于实验；测量验证先于解释；预注册判据先于执行；可复现性先于性能主张；负面结果、未决结果与无效结果保持区分；历史记录予以保留，而不是被悄悄改写。

每一项结果都连同其配置、种子、代码版本、测量定义、仪器检查与最终裁决一并记录。完整协议见 [`protocols/`](protocols/)，每条规则背后的理由见 [`docs/RESEARCH_PRINCIPLES.md`](docs/RESEARCH_PRINCIPLES.md)。
