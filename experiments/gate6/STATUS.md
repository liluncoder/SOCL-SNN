# Gate 6 — Self-modeling and higher-level integration

**Status: Conceptual.** No code, no preregistration, no run, and no criterion that could
currently be falsified.

A directory existing at this path does **not** mean this gate is open. There is nothing to
run here and no claim being made here.

## What would have to exist first

A definition of "self-modeling" that can be measured against a control condition — i.e.
something a system without a self-model would fail, and something a system could pass by
accident that would let us tell the difference. Until that definition exists, this stays a
conceptual direction.

## Where the concept lives

The long-term framing is in `docs/VISION_PAA.md`. That document describes a vision, not an
implemented architecture, and it does not license any claim at this gate.
